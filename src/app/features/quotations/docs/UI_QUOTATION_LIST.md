# UI — Listado de cotizaciones

## 2026-11-23 — Franja como clientes

El resumen es una franja de cinco columnas: Cotizaciones, Creadas, Convertidas, POS y Manual. Mismo alto y skeleton que clientes. En tablet quedan en tres columnas y en móvil en dos.

La cantidad de Cotizaciones es el total del filtro. El monto de esa columna, y el conteo y el monto de las otras, salen de la página visible.
