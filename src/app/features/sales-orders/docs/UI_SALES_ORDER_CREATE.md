# UI — Alta de orden de venta y cotización

## 2026-11-04

En Productos hay una sola lista. La búsqueda queda debajo de las pestañas. Al elegir un producto, el renglón entra a esa lista y ahí se edita unidad, lista, cantidad, precio, descuento, IVA e IEPS. No hay una segunda fila para confirmar.

IVA, cuando la razón social lo tiene activo, es un selector compacto (0, 8, 16 o la tasa del producto). El importe y el total siguen incluyendo el impuesto.

## 2026-11-03

El producto no se agrega en otro modal. La búsqueda es por código, SKU o nombre, y Enter toma el primer resultado. Código y disponible van en el nombre del renglón. Un servicio sin stock sí se puede agregar; un producto sin stock en la sucursal, no. El mismo flujo vale para cotización. La ventana abre a 1200px.

## 2026-11-04

Si el cliente tiene listas de precio, el selector Lista muestra solo esas. La predeterminada queda elegida al agregar un producto. Si el producto no tiene esa lista, se queda en Sugerido.
